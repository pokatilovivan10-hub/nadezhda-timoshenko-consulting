# Надежда Тимошенко — лендинг

Статический одностраничный сайт для GitHub Pages.

## Публикация

GitHub Pages публикует содержимое ветки `main` из корня репозитория.

## Важное перед запуском рекламы

Форма намеренно не передаёт персональные данные, пока не подключён защищённый серверный обработчик заявок и не утверждена политика конфиденциальности с реквизитами оператора.
